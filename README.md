# agence-jamal
application agence immobillure . transaction immobillire tout bien immobillier

## Langues

L’application propose le français (langue par défaut), l’anglais et l’arabe. Le sélecteur se trouve dans l’en-tête; la préférence est enregistrée séparément sur chaque appareil et n’est pas synchronisée avec les données de l’agence. L’arabe active l’affichage de droite à gauche. Les informations saisies dans les fiches restent inchangées; les libellés, les documents et les nouveaux textes d’annonce suivent la langue choisie.

## Recherche des biens

Chaque fiche de bien peut préciser une ville distincte de l’adresse. Dans la liste des biens, recherchez par texte ou filtrez par ville, type, transaction, statut et intervalle de prix. Les fiches clients permettent d’ajouter plusieurs villes et quartiers recherchés avec les champs répétables.

Les rapprochements classent les biens disponibles selon l’adéquation du budget, de la surface minimale, des villes et des quartiers. Les critères de prix, de surface et de localisation indiquent les écarts sans exclure automatiquement le bien; le type recherché et la transaction restent des critères de compatibilité.

Le tableau de bord présente aussi les biens dans des groupes repliables par type. Sélectionnez un bien pour ouvrir sa fiche.
